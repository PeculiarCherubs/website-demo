# Peculiar HQ Canonicalization

`Mother Church` is now a legacy name/identifier. The canonical worship location is:

```text
ID: peculiar-hq
Title: Peculiar HQ
Page: peculiar-hq.html
Type: hq
```

Legacy aliases remain recognized only for migration/runtime compatibility.

Peculiar HQ has the same reusable page systems as chapel pages: content,
HQ-specific broadcasts, HQ sermons, social content, and future HQ-only
services.

D1 uses the shared worship-location table with `location_type = hq | chapel`.

Untagged legacy sermons require an explicit location mapping during Stage 3;
they are never silently assigned to Peculiar HQ.
